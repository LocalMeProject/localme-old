# AI Agent ZIP Deployment Contract

Specification for AI model project generation and standard ZIP deployment.

## Deployment Package Structure

A complete LocalMe deployment artifact generated by an AI model consists of a single ZIP file containing:
- `localme.json` at the root: contains platform configuration (routes, roles, secrets, automations, settings).
- `codebase/` directory at the root: contains all static frontend files (HTML, CSS, JS, media).

## Interfaces

- `POST /api/projects/deploy` — Accepts `multipart/form-data` with `file` (the ZIP bundle) and optional `name`. Deploys or creates a project.
- `POST /api/import/all?projectId=N` — Restores or updates an existing project from a ZIP bundle.
- `/skills/localme/SKILL.md` — Plain-text agent skill serving prompt instructions and API contracts for AI models.

## Behavior

- All fields in `localme.json` are optional; missing values use safe defaults.
- All files inside `codebase/` are served at `/{username}/{project}/`.
- Static files are instantly live upon upload with cache invalidation.
